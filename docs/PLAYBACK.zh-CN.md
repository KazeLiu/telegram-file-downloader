# 在图库里播放图片和视频

> 本文描述**当前已经能用**的功能，基线为分支 `feat/playback-edge-parity`（2026-11-25 核对，播放器已按参考站复刻为寸止控制器）。
> 引擎、存储字段与结算规则的权威口径见 [寸止控制器实施契约](PLAYBACK-EDGE-CONTRACT.zh-CN.md)。

从菜单打开「节奏播放」，选择或新建播放列表，勾选图库，选择「混合」「仅图片」或「仅视频」，点击「开始播放」。播放列表、上次选择和喜欢收藏自动保存在当前浏览器，更换浏览器或清理网站数据后不会保留。

开始前的摘要随设置更新。播放设置按「玩法」「指令」「视频·图片」「声音」「其他」五组，也可用关键词查找；搜索显示所有匹配的分组，清空后回到原分类。玩法参数（难度、结局、时长、等待时间等）单独存在 `shicun.edge.v1`，与播放列表分开保存。

图库包括下载目录及小米相册已绑定的本地目录，包含子目录；重叠目录的同一路径只加入一次。此页面读取本地原文件，不直接播放云端原片，不移动、上传或删除文件。Docker 中的图库仍需挂载给程序。

## 每轮图片数与已展示去重

在「媒体」中设置每轮图片数，0 表示全部尚未展示的图片，最多可填写 100000。视频不占用图片数量。播放开始和循环换轮时，都排除当前浏览器已经展示过的图片，记录在不同播放列表间共用，刷新页面后也会保留。

- 图片成功加载、在前台播放器实际显示后才记入；预读、仍在加载、加载失败和队列中尚未展示的图片都不记入。
- 提前退出只排除已经看过的图片，队列中未展示的图片下次仍可入选；本轮的「上一项」仍可返回查看。
- 所选图库及收藏范围内的未展示图片不足指定数量时，开始新的图片周期，该范围内的图片重新参与。数量大于图库图片总数时，按实际总数选择。
- 每轮为 0 时，先播放剩余未展示图片，全部展示后再开启新周期。切换图库不会清除其他图库的记录，重叠目录按同一实际文件识别。

「循环列表」决定本轮结束后是否继续下一轮；关闭时播完本轮即结束。总时长到达时仍按计时结束，不强行展示剩余图片。

## 切图、自动播放和喜欢

- 点击图片或「下一项」切到下一张；「上一项」返回。键盘左右方向键和手机横向滑动也可切换。
- 图片默认每 8 秒切换，可在「播放设置」或播放器下方修改。仅图片列表可选择「按时间」或「按 BPM · 每拍一张」，播放中也能切换；混合列表仍按秒切图，视频保持原生播放。
- 按时间使用 1–300 秒的间隔，暂停保留剩余间隔。按 BPM 会启用节拍声，每响一拍切换一张，跟随当前显示的 BPM；BPM 可设 20–300，慢速为其 60%，红色（不许碰）阶段不切图。暂停后继续、修改模式或 BPM 时重新计一拍，不补播暂停期间的节拍。
- 关闭「自动切图」后可一直查看当前图片，BPM 切图对应的节拍声也停止；放大图片会关闭自动切图，避免查看时被切走。加载未完成时等待，不连续跳图追赶，实际速度仍受原图大小、网络与设备性能影响。
- 用 ＋ / − 放大缩小，点击百分比恢复完整显示。放大后可拖动查看图片。图片保持原比例，不裁切。
- 点击「喜欢」收藏当前媒体；在播放列表的「播放设置」里勾选「仅播放喜欢」，只播放所选图库中已收藏且符合媒体类型的文件。
- 视频使用浏览器原生播放器，支持进度拖动、音量和全屏。视频播完后进入下一项；关闭「循环列表」后，最后一项播放完成即结束。
- 点击「全屏」放大整个播放器；键盘 F 也可切换，Esc 退出。空格在焦点不位于表单、按钮或视频控制时暂停/继续；这些控件保留各自的键盘操作。

## 时长和节奏

玩法设置在「玩法」组：总时长 3/5/10/15/20/30 分钟或自定义 1–180 分钟，也可以选「随机」在 5–20 分钟间随机并隐藏剩余时间；推荐预设三档（第一次 / 标准 / 慢慢来·长时间）。总时长与播放列表的媒体设置互不影响。

「整局只玩一个部位」可选不限制 / 只玩乳头 / 只玩龟头：选中后整局只出该部位的专属指令（乳头 18 条、龟头 16 条，含 2 条寸止指令），中途的「只玩乳头 / 只玩龟头」插入段同时停用；只玩乳头拿到许可时，奖励屏会多一句「现在可以摸下面了。」。

「只玩乳头 / 只玩龟头」（不限定部位时）会在整局中途插入 1–4 段专属指令，每段 20–30 秒，两段之间至少隔一条普通指令。

播放中按「可以撸（绿）」「慢慢来（黄）」「不许碰（红）」三档循环，各档的时间占比与单条秒数由难度决定（简单 85% / 普通 70% / 困难 50% / 地狱 30% 的最终许可率），也可以在「自己调」里改许可概率与三档占比。指令时长的「较长」「很长」档只拉长绿色和黄色指令，红色永远不吃倍率。

节拍声按当前指令自带的 BPM 打拍（绿色与黄色不同音高：880 Hz / 520 Hz），红色可以改成只有心跳、心跳＋节拍、只有节拍三种。**全部声音都是浏览器实时合成的，不加载任何音频文件，也没有语音播报。**

暂停会停止图片倒计时、视频和节奏；切到后台也会自动暂停，返回后点击继续。切换菜单或退出工作台会结束本次播放，列表设置和喜欢收藏保留。

播放器右上角的「音量」按钮里是五条滑杆：视频音量 0–100%、节拍声 0–300%、指令文字不透明度 30–100%、指令文字大小 60–100%、视频变暗程度 0–100%。节拍声上限 300%，被视频声音盖过时可以调高（旧版只有 100%，是「声音过小」的根因）。隐藏时间与进度条不改变结束时刻，变暗程度只影响播放器画面（0% 完全透明等于视频原本的亮度，100% 是 0.45 的暗色遮罩）。

## 播放中的操作与结束

播放中整层覆盖整个视口，全局导航与页头会被隐藏；退出播放后立刻恢复。版式照参考站复刻：顶栏、中央、底部三块分区，信息按四角分层。背景是随模式变色的四层径向光晕（绿 / 黄 / 红，0.8 秒过渡），媒体铺在下面并按变暗设置盖一层黑色遮罩。

顶栏左侧是「第 N 条指令」和「忍住 N」次数，中间是剩余时间（可在设置里隐藏）。右侧一排圆形图标按钮：

- **显示完整画面（不裁切）**：在「铺满裁切」与「完整画面」之间切换，图片和视频都生效。
- **悬浮窗**：把当前视频放进画中画小窗，边浏览别的网页边看；图片没有对应能力，按钮为禁用。
- **音量**：打开音量弹层——视频音量 0–100%、节拍声 0–300%、指令文字不透明度 30–100%、指令文字大小 60–100%、视频变暗程度 0–100%。
- **横屏**：只在触屏设备出现，尝试锁定横屏。
- **全屏**：只在宽屏出现，与按 F 同一个动作。

图标右侧是「全屏」「暂停／继续」「退出」三个药丸按钮。暂停时顶栏文案变成「继续」，中央的药丸变成「已暂停」并隐藏 BPM，主按钮变灰，剩余时间冻结。

中央从上到下：模式胶囊（可以撸／慢慢来／不许碰，带模式色描边、字距 0.25em）与「N BPM」加一个随节拍跳动的圆点、当前指令（48px 粗体，按「。！？」逐句换行不切断词）、这条指令专属的小字提示、这一条的倒计时条（160×4px，按剩余时间向右收缩）、「忍住了」圆角主按钮（按下即切到「等它平息」）、提示「在快射的前一刻停下来了就按。按下后切换成“等它平息”」，最后是「射了」文字按钮（点击先弹二次确认「记为中途结束的一局吗？／记录并结束／继续」）。

拿到许可时盖一层整屏奖励屏：粉色（松手射精时为橙色）径向渐变、眉标 Permission / Ruined、大标题「可以射了」／「可以射」、白色倒计时条与「剩余 N 秒」。

底部两行：整场进度条（8px）与「已用 / 总时长」（许可窗口期间整条变白发光并显示「许可 N 秒」）、图例（可以撸／慢慢来／不许碰三色点，宽屏追加「Space 暂停 · E 忍住 · Esc 退出」）与「换个视频」药丸。再上面的控制带有换一项、喜欢、文字不透明度与字号加减、设置、结束。

播放中点「结束」立即停止并显示结算屏；点「退出」会先确认再回到播放列表。结算屏按结局分四套文案（Finished 坚持到底了／Ruined 松手收场／Denied 今天被禁止了／Lost 没忍住，射了），带三格统计（时间／指令／忍住）和「再来一次」「返回播放列表」。两条路都不会删除文件，已展示记录与喜欢收藏照常保留。

设置页头部会显示「连续 N 天」的打卡（每天玩一次就 +1，断一天清零，里程碑是 3/7/14/30 天后每 30 天一个）、「记录 N」入口与「与默认不同的项目：N」。点「记录」打开历史成绩：累计次数与各结局分解、最近 30 局的列表与详情（时间、指令数、忍住次数、难度、中途结束撑了多久、加时次数），每条都能单独删除、也能整机清空。这些数据全部只存在这台设备的 localStorage 里。

「加时赛」结局没抽中会加时（每次加时许可率 +15%，第 5 次必给许可）：加时会插一条 6 秒的红色指令，时长按「加时长度」决定（短 1–3 分钟／普通 2–5 分钟／越来越短：5–10 → 3–5 → 2–3 → 1 分钟），顶栏提示「加时第 N 次 · 时间增加了 m:ss」。「连续」结局把许可窗口固定成 100 秒：窗口里每 25 秒换一条「再来一次」（共 4 条），100 秒走完算成功，不会再重开一轮。

## 播放中改设置

播放中的设置从控制带的「设置」进入，会打开玩法、指令、声音、其他四组参数；「视频·图片」组在播放中隐藏（改图库或顺序必须回列表），配置管理与列表编辑也不在播放中提供。关闭设置后需要自己点「继续」，不会自动恢复，也不会重建队列或跳回第一项。

视频音量 0–100%、节拍声与心跳声 0–300%；BPM 切图静音后仍按拍切换。隐藏时间只藏起时间与进度条，不改变结束时刻；亮度只影响播放器画面，最低 20%。「红色时也继续播放视频」关掉时，红色指令会暂停视频并额外压暗；「每换一条指令就换一个视频」打开时，指令前进就切到下一个视频。

切到后台会自动暂停，回到页面时给出提示等你点继续；浏览器会限制隐藏页面的定时器，因此不保证后台继续切图。

## 列表与图库

播放列表可以新建和删除。删除只移除这份配置，不动图库里的文件；喜欢收藏与已展示记录独立保存。某个图库在本机被移走后，引用它的播放列表会跳过这一项并给出提示，其余图库照常播放，不必重建列表。

「混合」「仅图片」「仅视频」三选一决定入队内容，不影响计时或声音。

## 本机存储异常时

配置存在浏览器本机（媒体层 `shicun.playback.v1`，玩法层 `shicun.edge.v1`）。若这份数据损坏或无法读取，页面会提示并提供两个入口：重新保存当前内容，或「重置播放设置」。**重置会清空全部播放列表、喜欢收藏和已展示记录**，只作为最后的退路。

## 加载与配置管理

媒体清单按文件名顺序每 20 项流式返回，够首批播放后即可进入播放器，后续清单继续补充。设置了每轮数量时，需先找到足够的未展示图片；不足时需等目录扫描结束，才能决定重启图片周期。底部文件名行「当前项／总项」末尾的「+」表示清单仍在补充（这一行属于播放器底部的控制带，不是屏幕角落）。清单读取过程中可以随时取消，不必等它扫完。

图片优先读取当前项，再用两个并发连接滚动预取最多 20 张；只在内存里保留已取回的数据，不同时解码全部图片，离开播放时释放缓存。文件名顺序保持不变，随机模式打乱到达的批次和后续轮次。预取文件在展示前仍向服务端校验版本，不再重复下载整张原图。视频继续使用原生流式播放，不预下载整个视频。

> 服务端 `/api/playback/media` 是按原文件直出（`FileResponse`），没有压缩或转码链路，所以"缓存"的是原图数据，不是压缩副本。需要更省流量的做法（服务端缩略图或转码）目前**没有实现**。

「配置管理」可导出 JSON、导入 JSON、恢复当前列表默认参数。导出不包含原文件、图库路径、喜欢、已展示记录或登录信息；导入先验证并确认替换播放列表，图库需在当前设备重新选择，已有喜欢和已展示记录保留。恢复默认只改当前列表的参数，保留名称、图库、喜欢及已展示记录。

## 文件打不开时

播放器会停下来显示错误，可重新加载、手动切到下一项，或返回列表重新开始以刷新文件清单。文件被移动、回收或替换后不会继续读取旧版本。

视频容器和编解码支持取决于浏览器；本功能不进行转码。若视频无法播放，可先尝试同一文件的 MP4（H.264/AAC）版本。全屏和声音也受浏览器及系统权限影响。

参考页面的设置控件、运行层布局，以及**参考页能力 → 本项目现状的逐项对照与优先级**，见 [功能与交互参考](PLAYBACK-INTERACTION-REFERENCE.zh-CN.md)；运行、暂停、退出与自然结束的实际反馈，见 [运行界面实查](PLAYBACK-RUNTIME-INTERACTIONS.zh-CN.md)。

## 图片切换实现

- `web/src/playback.ts`：沿用 `shicun.playback.v1`，`schemaVersion` 升到 4，只保留媒体层字段；旧 v1–v3 列表升级后会丢弃已作废的玩法字段，原有列表、图库和喜欢保留；格式错误仍报错。`shownImages` 只由已展示图片写入，队列选择与预取不会消费图片。
- `web/src/PlaybackPanel.vue`：仅图片列表的 BPM 模式由同一次节拍回调切换图片并发声，不再同时运行秒数切图。首张图片先显示完整一拍；队列结束时停止，不额外发出没有对应下一张的节拍。时间模式和混合列表继续使用原图片倒计时。
- 调度使用单调时钟和上一拍截止时间；回调晚到时不逐渐累积漂移，错过多拍时不突发补拍。隐藏页面、暂停、读取失败和退出仍沿用现有停止逻辑。
- `web/src/playbackLoader.ts` 处理流式清单和限量图片缓存；服务端新增 `/api/playback/queue/stream` 与媒体 HEAD 版本校验，原 `/api/playback/queue` 保留。文件仍受既有目录边界、权限和版本校验保护，不新增依赖。
