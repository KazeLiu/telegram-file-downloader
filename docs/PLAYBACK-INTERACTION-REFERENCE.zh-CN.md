# 通用节奏播放器：功能、界面与使用逻辑

参考页面：[参考网页](https://100adults.com/zh/sundome)。查阅日期：2026-11-13，Chrome 桌面版（视口 926×624），通过已授权的浏览器插件逐标签读取控件文本与顺序。

本文只梳理**交互形态**：进入流程、设置卡片结构、五个分类的字段、计时与节拍、声音、显示与配置管理、运行层的四角布局。不复制参考页的文案、素材、样式与专用业务规则。

依据分三类：

- **页面实查**：本篇 2026-11-13 在 Chrome 里逐项读取的控件、标签文字、默认值与排列顺序。
- **页面说明**：参考页「更新记录」「FEATURES」「HOW TO PLAY」「FAQ」等处公开描述的行为，未逐项操作确认。
- **本项目适配**：面向本项目的布局与行为建议，不代表参考页如此，也不代表已实现。

**本项目现状基线：提交 `0dbf352`（2026-11-13）。** 运行、暂停、完成的实际操作记录另见 [运行界面实查](PLAYBACK-RUNTIME-INTERACTIONS.zh-CN.md)；面向使用者的现有功能见 [播放器使用说明](PLAYBACK.zh-CN.md)。

## 1. 进入流程：落地页 → 年龄门槛 → 同地址切到设置

参考页把「宣传」和「可用界面」放在同一个地址里，靠状态切换，不换 URL。

1. **落地页**：页头有外站链接与 Tools 导航（寸止游戏／戒色计数器／阴茎尺寸百分位／持久时间百分位）、语言菜单（15 种）、可关闭的功能公告条。主体是标题、一段玩法说明、三个版本入口（女性／男同版／女同版）、语言选择（简体／繁體）、一排特性标签（免费／无需注册／支持手机／节拍器／语音播报／忍住计数／数据只存本机）。
2. **年龄门槛**：标题「准备好忍住了吗？」，主按钮「已满18岁，开始玩 →」，另有「我未满18岁」跳外站。
3. **点主按钮**：地址不变，同页切换成设置态，没有独立的新路由，浏览器后退可用。
4. 落地页下方还有更新记录、FEATURES、WHAT IS THIS、HOW TO PLAY、TIPS、建议表单、REQUESTS、FAQ、免责声明与姊妹站推广。**这些是内容区，不是播放器的一部分。**

### 本项目适配

- 宣传页与播放器不合并。`/#/playback` 是独立入口，直接进入设置，不做年龄门槛（本项目是通用图库播放器）。
- 需要同地址切态的是 **设置 → 运行 → 完成** 这三态，可参考其「不跳路由」的做法（见第 8 节与运行实查）。
- 特性标签式的「一句话卖点」不搬。

## 2. 设置卡片总结构

设置是页面中央的一张纵向卡片（不是全屏弹窗），实测从上到下：

1. **标题行**：`设置` + **当前配置摘要**（实测 `10分钟 · 普通 · 抽签 · 指令 81种`）。
2. **搜索框**：placeholder 为 `搜索设置（例：乳头、左手、速度、视频）`，位于标签栏上方。
3. **横向标签栏**：`玩法`／`指令`／`视频·图片`／`声音`／`其他`，一次只显示一个面板（tabpanel）。
4. **当前分类内容**：纵向排列，一行一个设置项；说明文字在标签下方或右侧。
5. **底部主按钮**：`开始`；其下另有一个 `让别人远程指挥你（生成链接）` 入口，与普通设置项分开。
6. **卡片外的侧边说明**：绿色／黄色／红色三段图例（"屏幕是绿色时可以撸…变红就松手"），以及一段玩法结算说明。

摘要行是当前配置的**汇总视图**，随表单实时变化，不是独立存储。

### 本项目适配

保留 `/#/playback` 单页入口。现有分组是「播放／媒体／声音／显示／配置管理」，可以并存「顶部摘要行 + 关键词搜索 + 分组标签」这套骨架，但**不必照搬参考页的分类名与数量**（本项目没有"指令""口吻"这类概念，对应物是阶段与提示）。

摘要建议字段：列表名、媒体类型、顺序、切图方式（按时间／按 BPM）、总时长、声音开关。

## 3. 分类「玩法」逐字段（实查）

| 顺序 | 设置项 | 控件 | 取值／默认 | 说明文字要点 |
| --- | --- | --- | --- | --- |
| 1 | 推荐 | 单选组 | 第一次／**标准**／慢慢来·长时间 | 选中后下方回显摘要 |
| 2 | 只玩乳头的时间 | 帮助按钮 + 开关 | 默认关 | 中途插入一两段只准摸乳头、下面不许碰的时间 |
| 3 | 为谁而写 | 单选组 | **男性**／女性／男同版／女同版 | 切换整套词库与素材 |
| 4 | 时间 | 单选组 | 3／5／10（默认）／15／20／30 分钟／自定义／随机 | 自定义 1–180 分钟；随机 5–20 分钟且不显示剩余时间 |
| 5 | 难度 | 单选组 + **色条** | 简单／**普通**／困难／地狱 | 「动手六成·慢两成·不许碰两成。最后获得许可的概率70%」；下方色条按绿／黄／红比例绘制 |
| 6 | 自己调 | 折叠区（DisclosureTriangle） | 折叠 | 展开后分别调绿／黄／红三比例（合计恒 100%，调一个另两个自动增减），并可单独设最后许可概率 |
| 7 | 结局 | 单选组 | **抽签**／必定允许／必定禁止／松手射精／连续（多少次都行）／加时赛 | 抽签按难度对应概率，每忍住一次 +5%，最多 +20% |
| 8 | 获得许可时以「松手射精」结束 | 开关 | 默认关 | 仅结局为抽签／加时赛时出现 |
| 9 | 允许射精的时间 | 单选组 | 5／**10**／20／30／45／60 秒 | 决定最后阶段白色进度条的长度 |
| 10 | 忍住后等待的时间 | 单选组（随机／固定）+ 两个数字输入 | **随机**；预设 8～16（默认）／10～40／20～60 秒；固定档另有「最短 8」「最长 16」 | 每次随机，长度不同 |
| 11 | 指令时长 | 单选组 | **标准**／较长（约 1～2 分钟）／很长（约 2～5 分钟） | 只影响"撸"类指令，红色与写明秒数的指令不变 |
| 12 | 两人同时玩 | 说明 + 按钮 | — | 「生成双人链接」，2 分钟后双方自动开始 |
| 13 | 边看别的视频边玩 | 说明 + 复选框 | 默认未勾 | 「开始后提示我打开小窗」 |
| 14 | 让对方远程下指令 | 说明 + 3 步有序列表 + 两套子块 | — | 子块一「发给指定的人」→ 按钮「生成发给对方的链接」（可附一句话文字）；子块二「在 X 等平台征人」→ 按钮「征人来给我下指令」（只能按钮+固定短句） |

要点：

- **难度 = 时间比例**（绿／黄／红），不是抽象等级；色条是这个比例的**可视化**，属于"让用户看见自己选了什么"的好做法。
- 「自己调」把同一组比例变成可编辑状态，且**约束合计 100%**：调一个，其他跟着动。
- 联机类入口（12–14）全部放在同一分类末尾，与本地设置项明显分开。

### 本项目适配

- 难度色条 → 本项目对应「慢速／快速／休息」三阶段占比，可用同一条色条表达，且**用 CSS 绘制**，不做图片。
- 「自己调」的三比例联动 → 可以直接复用：三档权重合计 100%，改一个另两个按比例回填。
- 预设（第一次／标准／慢慢来）→ 可作为"一键套用三阶段参数"的预设，P2。
- 双人链接、远程指挥、征人 = 参考页专用联机能力，**本项目不做**（见第 9 节）。

## 4. 分类「指令」逐字段（实查）

- **添加自己的指令**：说明"只保存在本机。最多30条。"；类型单选 `撸（绿）`／`慢（黄）`／`不许碰（红）`／`只玩乳头（粉）`／`只玩龟头（蓝）`；右侧「添加」按钮。
- **你有的道具**：复选框 `飞机杯`／`前列腺按摩器`；说明"只选你手上有的。会混入适合该道具的指令。"
- **指令类型**（多开）：基础指令（绿·黄·红）始终包含；可选 `整局只玩一个部位`（不限制／只玩乳头／只玩龟头）、`寸止指令`、`挑逗`、`姿势·羞耻`、`轻度疼痛`、`只玩乳头的时间`、`只玩龟头的时间`，每项带一行说明。
- **口吻**：说明"同时打开两个以上时，每条指令轮流使用"；项 `强硬`／`挑逗`／`辱骂`／`温柔（像恋人一样）`／`恋足羞辱`，各带一行说明与"优先男声／女声"。
- **惯用手**：`右手`／`左手`；说明"选左手后，内置指令里的『右手』『左手』会互换。自己添加的指令不会更改"。
- **逐条选择指令**：折叠按钮 `打开列表` + 计数 `已启用 88 / 88`；说明"男性版和女性版分开保存"。

要点：

- **"开关组 + 每项一行解释 + 计数回显"** 是这一页反复出现的模式；计数（88 / 88、81 种）让用户在不开列表的情况下知道影响面。
- 折叠列表用于长清单，避免卡片无限拉长。

### 本项目适配

本项目没有指令库，对等物是**播放项与阶段名称**。可借鉴的只有结构：多处使用「开关组 + 单行说明 + 数量回显」，以及长清单折叠。

## 5. 分类「视频·图片」逐字段（实查）

| 设置项 | 控件 | 默认 | 说明要点 |
| --- | --- | --- | --- |
| 播放视频 | 开关（分类顶部） | 开 | 作为背景播放，配合指令；暂停方式、声音、明暗在下方调整 |
| 自己选视频 / 播放自己的视频和图片 | 说明 + 按钮 `选择`／`选择视频／图片`／`选择整个文件夹` + 复选 `下次继续用这些` | — | 本机文件**不上传**；图片每张 12 秒；勾选后保存在本设备，**超过 1GB 的视频不保存**；「可以添加多个」 |
| 环境提示 | 说明 + 外链 | — | 部分视频需特定网络环境才可播放 |
| 视频声音 | 单选 | 一直开／关／只在最后（获得许可时） | 会和节拍声混在一起 |
| 视频音量 | 滑块 | 100% | — |
| 指令文字不透明度 | 滑块 | 100%，范围 30～100% | 文字与暗色光晕浓度；调低可透过文字看到视频 |
| 指令文字大小 | 滑块 | 100%，范围 60～100% | 只缩文字，画面变多 |
| 视频变暗程度 | 滑块 | 100% | 0% = 完全透明不加遮罩；100% = 原来亮度 |
| 忍住后的等待时间也播放 | 开关 | 开 | 关 = 等待时暂停并变暗 |
| 红色（不许碰）时也继续播放视频 | 开关 | 关 | 关 = 红色时暂停并变暗 |
| 每换一条指令就换一个视频 | 开关 | 关 | 开 = 每条指令切下一个；关 = 播完再换 |
| 视频从中间开始播放 | 开关 | — | 跳过片头打招呼与采访 |
| 显示完整画面（不裁切） | 开关 | 关 | 关 = 铺满（竖屏左右裁切）；开 = 完整显示，上下留黑边 |
| 类型 | 单选 `全部（混合）`／`自选混合` | 全部 | 从热门类型各取几部混播 |
| 屏蔽熟女 | 开关 | — | 两种模式都生效 |
| 去重记录 | 说明 | — | 本设备记住看过的视频，避免重复 |

要点：

- **"不裁切" 是一个显式开关**，默认关闭（铺满屏）；这与"原图默认完整显示"是相反的默认值，取舍要写清。
- 音量、透明度、字号、变暗**四个滑块各带一行"0%／100% 分别意味着什么"**，不靠用户猜。

### 本项目适配

- 本项目**直接使用已挂载的图库**，不要求每次选文件；「选择整个文件夹」等入口不需要。
- 原图默认完整显示，不改成裁切铺满；如需铺满可作为可选开关。
- 「变暗程度」「文字不透明度」「文字大小」三个滑块是运行层可读性的真实痛点，建议一并提供（现有 `brightness` 20–100 已覆盖其一的语义）。
- 「每换一条指令就换一个视频」对应本项目的「换阶段是否跳下一张」，即 P2。
- 「去重记录」本项目已用 `shownImages` 实现，语义更强（跨轮排除）。

## 6. 分类「声音」逐字段（实查）

- **节拍声（节拍器）**：开关 + 音量滑块 100%（**最高 300%**）；说明"按指令的速度轻声打拍子。灯光节拍始终显示"「100%=和以前一样，被视频声音盖过就调高」。
- **心跳声（氛围）**：开关（"不许碰"时播放低沉心跳）+ 独立音量 100%（最高 300%）。
- **语音播报指令**：开关；说明"不用看屏幕。使用设备的中文语音"。
- **边听音乐边玩**：开关；说明"在 iPhone、iPad 上不打断其他 App 的音乐，把节拍、心跳和视频声音叠在上面播放。开启后，静音开关打开时节拍和心跳不会响。播报指令时音乐会变小。"
- **测试语音播报**：按钮（试听，实查未点击）。
- **切换时振动**：开关（仅手机；"不许碰"时振动更久）。
- **红色时的节拍声**：单选 `只有心跳`／`心跳＋节拍器`／`只有节拍器`。
- **心跳跟随 BPM**：开关；关掉后红色带 BPM 时心跳保持固定节奏。
- **振动的时机**：多选 `指令切换时`／`按"忍住了"时`／`结局（许可·结束）时`。
- **播报的声音**：单选 `自动（按口吻）`／`男声`／`女声`／`设备默认`。
- **播报的人**（真人级合成音）：单选 `自动`／`云希（明亮）`／`云健（低沉）`／`云扬（沉稳）`／`雲哲（台灣）`／`晓伊（活泼）`／`晓晓（温柔）`／`曉臻（台灣）`／`手机自带的朗读`；说明"真人级合成语音，整局都是同一个人。自己写的指令仍用手机自带的朗读"。
- **按名称选择声音**：下拉 `不指定（自动）` + 本机已安装中文声音列表（实测 Microsoft Huihui/Kangkang/Yaoyao、Google zh-CN/zh-HK/zh-TW）；带「测试语音播报」按钮；说明"如果男声/女声播出来不对，可以在这里试听后直接选一个"。
- **语速**：`0.8×`／`1.0×`／`1.2×`。
- **音高**：`自动`／`低`／`标准`／`高`。
- **口吻短句**：三组独立控件 — 显示在屏幕上／读出来（开关）；放在指令前／放在指令后／不放（单选）；一半／每次（单选）。

要点：

- **同一种声音有两条选择路径**：语义档（男声/女声）+ 具体设备声音（按名称），后者带试听。这是"设备语音不可控"的现实妥协，值得学。
- **音量上限 300%** 是为了被视频声音盖过时还能听清；本项目不必然需要，但"节拍音量独立于媒体音量"是关键。

### 本项目适配

本项目**没有语音播报引擎**，只有浏览器的 `speechSynthesis`（阶段名称播报已实现）。可借鉴：

- 节拍音与媒体音量**分开**（已实现：`beatVolume` / `mediaVolume`）。
- 语速 0.8／1.0／1.2（已实现 `speechRate`）；可选增加音高。
- 「按名称选择声音 + 试听」是拿到设备语音的唯一可靠方式，**建议实现**（当前只有固定中文声音）。
- 呼吸声/环境声（参考页的"心跳"）本项目不做。
- 振动、边听音乐边玩（`audioSession`）只在移动端有意义，属 P2。

## 7. 分类「其他」逐字段（实查）

- **隐藏剩余时间**：开关；"游戏中隐藏上方计时和下方进度条。结束时间不变。"
- **镜子（用前置摄像头看自己）**：开关 + 位置单选 `铺满背景（调暗）`／`右下角小窗`；说明"画面不会离开你的设备（不录像、不保存、不上传）"；"播放视频时会固定为右下角小窗"。
- **保存与恢复设置**：`导出（JSON）`／`导入`／`生成分享链接`／`恢复默认设置`；说明"把指令开关、BPM、自定义指令和视频设置导出为 JSON，在其他设备导入即可得到相同设置"。

### 本项目适配

- 隐藏剩余时间**已实现**（`hideTime`），保留。
- 摄像头预览 = 参考页专用，**不做**（涉及权限、隐私、与本项目无关）。
- 导出／导入**已实现**（不含原文件路径、喜欢与已展示记录）；「生成分享链接」= 需要服务端，**不做**；「恢复默认」已实现。

## 8. 运行层：覆盖视口 + 四角分层（实查 + 公开说明）

详见 [运行界面实查](PLAYBACK-RUNTIME-INTERACTIONS.zh-CN.md)。这里只留下对本项目有用、且已被证实的部分：

```text
┌ 左上：序号/计数 ──────────── 右上：剩余时间  小窗  全屏  暂停  退出 ┐
│                                                                  │
│                        中央：阶段 + BPM                          │
│                        大字号提示（主阅读区）                     │
│                        主操作 / 次操作                            │
│                                                                  │
├ 底部：已用／总时长 ────────────────────────────── 总体进度 ────────┤
│                        图例与键盘提示                             │
└──────────────────────────────────────────────────────────────────┘
```

- 运行层**覆盖整个视口**，但不是浏览器全屏（`requestFullscreen` 未调用）；两者分开。
- 暂停时：同位置按钮变「继续」，中央显示「已暂停」且 BPM 隐藏，主操作禁用，下方出现「查看操作说明」，计时冻结。
- 首次引导覆盖在运行层上（2026-11-12 实查为 5 步；2026-11-13 抓到的当前版本为 **1 / 9**，说明步数已被扩到 9 步），带「跳过」「下一步」，末步进入运行。
- 退出：直接回设置页，无二次确认、无完成卡。
- 自然结束：覆盖层消失，设置页出现「坚持到底了」+ FINISHED 完成区。
- 启动前会出现「广告」弹窗（"关闭并开始"）——参考页行为，**本项目不实现**。
- 公开说明另有：右上角音量入口、横屏入口；视频左右两侧**双击后退/前进 10 秒**；悬浮小窗（打开时原页视频暂停）；桌面快捷键 `Space` 暂停、`E` 申报、`Esc` 退出。

### 本项目适配（建议布局）

```text
┌ 返回播放列表 ────── 列表名称 ───────── 设置／音量／全屏／退出 ┐
│                                                          │
│                      图片或视频（铺满）                    │
│                                                          │
│                中央：阶段名 + BPM + 说明                  │
│                                                          │
├ 已用／总时长 ─────────────────────────── 总进度条 ────────┤
│ 当前文件名 ─────────────────────────── 当前项／总项        │
│      上一项　暂停／继续　下一项　喜欢　结束                │
└──────────────────────────────────────────────────────────┘
```

规则：同位置切换暂停/继续；「结束」与「返回播放列表」都不删文件；播放中打开设置面板不重建队列；窄屏允许辅助信息换行，但暂停/切换/退出必须保持可点。

## 10. 使用流程与状态转换（本项目契约）

```text
选择列表、图库、媒体类型 → 配置参数 → 开始
                                     ↓
                                  加载媒体
                                     ↓
                         播放中 ←→ 用户暂停
                            ↓
         总时长到达／非循环队列结束／用户结束
                            ↓
                         完成界面 → 返回播放列表
```

- **开始前**：图库与媒体类型有效，至少一个可播放项；配置错误留在表单修正。
- **加载**：显示加载中；未就绪的图片不消耗完整展示间隔，不突发补拍。
- **播放中**：手动、定时、BPM、视频结束走同一个"下一项"逻辑。
- **暂停**：保留当前媒体、视频位置与剩余间隔；继续不是重开。
- **读取失败**：停止自动推进，显示原因，提供重试与下一项。
- **完成**：停媒体/节拍/播报，只显示结束提示与返回入口，保留列表与收藏。不加成绩、历史、分享。
- **刷新或离开**：只保存配置与收藏，不恢复运行会话；页面隐藏自动暂停。

## 11. 后续接手时先区分现状与新增项

已实现功能见 [播放器使用说明](PLAYBACK.zh-CN.md)；代码主要在 `web/src/PlaybackPanel.vue`、`web/src/playback.ts`、`web/src/playbackLoader.ts`，服务端 `/api/playback/queue/stream` 与 `/api/playback/media`。

优先级（与第 9 节一致）：**P1 = 运行层沉浸化、暂停/完成反馈、Esc 退出、首次引导**；P2 = 色条、滑块组、选声音+试听、双击 seek、序号计数；**不做** = 联机、摄像头、分享链接、广告、成绩体系。
