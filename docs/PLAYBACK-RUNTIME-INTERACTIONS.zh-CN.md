# 运行、暂停与完成界面：实查交互记录

来源：[参考页面](https://100adults.com/zh/sundome)。查阅日期：2026-11-12，使用 Chrome 桌面版，通过已授权的浏览器插件操作。

本文记录通用播放器的布局、按钮反馈与状态转换，配合 [功能与交互参考](PLAYBACK-INTERACTION-REFERENCE.zh-CN.md) 阅读。参考页的专用内容和业务按钮不纳入功能设计。

实查使用 1 分钟会话，背景媒体、节拍声、氛围声和语音均关闭。分别观察了暂停后退出和等待自然结束。没有选入用户照片，也没有连接其他设备。

## 1. 状态在同一页面内切换，不是跳转到新路由

设置、运行、暂停和完成时，地址都保持为参考页原地址。运行区是覆盖整个网页视口的界面；退出后露出原设置页。

```text
设置 → 开始 → 启动前弹窗（本次出现）
                    ↓ 关闭并开始
            首次操作引导 → 开始 → 运行中
                                  ↓ 暂停
                                已暂停
                                  ├ 查看操作说明 → 引导 → 跳过 → 仍暂停
                                  └ 退出 → 设置

运行中 → 计时自然结束 → 完成提示
```

暂停后，原位置的按钮变为「继续」。该按钮的显示已确认，本次没有单独点击它核对恢复后的首帧和计时。

## 2. 运行界面：工具集中在右上，主内容留在中央

观察时浏览器内容区域约为 2363 × 975 CSS 像素。运行区覆盖整个视口，但浏览器全屏 API 并未启用；“占满网页”与“进入浏览器全屏”是两件事。

```text
┌ 当前序号／状态计数 ─────── 剩余时间　小窗　全屏　暂停　退出 ┐
│                                                          │
│                        当前阶段                          │
│                           BPM                            │
│                     大字号当前提示                       │
│                                                          │
│                       主操作区域                         │
│                       次要操作区域                       │
│                                                          │
├ 已用时间／总时长 ─────────────────────────────── 总进度 ────┤
│                     图例与键盘提示                        │
└──────────────────────────────────────────────────────────┘
```

- **左上角**：当前序号和状态计数，属于辅助信息。
- **右上角**：先显示剩余时间，其后从左到右依次为悬浮窗图标、全屏、暂停／继续、退出。
- **中央**：阶段、BPM 和大字号提示构成主要阅读区域，操作区域在提示下方。
- **底部**：已用时间／总时长、整体进度、状态图例及键盘提示。

以上描述相对位置，不要求本项目照搬像素尺寸。主内容下方的专用业务按钮没有点击，不据此推断其触发规则。关闭媒体和声音时，右上角没有显示音量按钮；不能据此认定其他配置下也没有。

## 3. 开始前弹窗与首次引导

### 启动前弹窗

两次点击开始后，都出现了标为「广告」的页内弹窗。角落关闭图标和正文按钮均提供「关闭并开始」操作；关闭后进入会话，没有观察到外部网页跳转。弹窗出现频率和自动关闭规则未测量。

这是参考页行为，不纳入本项目的实现要求。

### 首次操作引导

首次进入会话出现五步引导，覆盖在运行界面上。此时会话处于暂停状态，剩余时间为 1:00，已用时间为 0:00。

| 位置／控件 | 点击反馈 |
| --- | --- |
| 引导上方的步骤编号 | 显示当前步骤／总步骤，如 1/5 |
| 引导主体 | 展示当前说明，随步骤改变内容及指向的界面区域 |
| 左下「跳过」 | 关闭引导；从暂停页重新打开时，跳过后仍保持暂停 |
| 右下「下一步」 | 切换到下一步，不离开当前页面 |
| 最后一步右下「开始」 | 关闭首次引导，进入运行状态 |

首次引导与暂停后的帮助入口共用这套五步界面。引导的通用结构可参考，不复用原页专用说明内容。

## 4. 暂停不是退出，也不会重新开始

点击右上角「暂停」后，实际变化如下：

1. 同一位置的按钮变为「继续」。
2. 中央显示「已暂停」，原 BPM 文字不再显示，当前提示保留。
3. 剩余时间和已用时间停止推进。
4. 中央主操作按钮变为禁用；其下出现「查看操作说明」。
5. 仍停留在运行覆盖层中，没有返回设置，也没有出现完成提示。

实查暂停时显示剩余 0:48、已用 0:13／1:00。继续查看工具栏和引导后，剩余时间仍为 0:48，表明暂停期间没有消耗这段时间。两处计时显示的取整关系没有测量。

点击「查看操作说明」后，引导从 1/5 重新开始。点击「跳过」关闭引导，回到原暂停画面，剩余时间仍为 0:48，不会自动继续。

## 5. 右上角按钮：实测结果与未确认项

| 按钮 | 所在位置 | 实际反馈／确认范围 |
| --- | --- | --- |
| 悬浮窗图标 | 剩余时间后，第一个工具按钮 | 已点击，未观察到成功打开的小窗；后续读取按钮仍为未启用，未确认小窗布局 |
| 全屏 | 悬浮窗右侧 | 已点击，未成功进入浏览器全屏；按钮仍显示「全屏」，不能将本次环境表现当成所有浏览器的行为 |
| 暂停 | 全屏右侧 | 切换为「继续」，显示暂停状态，计时停止，详见上一节 |
| 继续 | 原暂停按钮位置 | 暂停后显示；恢复动作未单独点击验证 |
| 退出 | 最右侧 | 从暂停状态点击后，运行覆盖层直接消失并返回设置，没有二次确认，也没有完成卡片 |

退出时没有观察到页内确认弹窗或浏览器原生确认框，地址没有变化。这次只核对了**从暂停状态退出**，没有另测运行中直接退出。

页面帮助列出的 Space／Esc 快捷键本次未逐项操作，不能将说明文字当作实测结果。

## 6. 自然结束与主动退出走不同的显示路径

第二次会话设置为 1 分钟，没有使用中央业务操作，等待计时自然结束：

- 运行覆盖层自动消失。
- 原页面显示完成区域，标题为「坚持到底了」，带有 FINISHED 标识。
- 地址仍未改变，设置区域继续保留在页面中。
- 结束后还出现了「添加到主屏幕」提示；点击「以后再说」后提示关闭，完成区域保留，没有进行安装。

没有捕捉到恰好归零那一帧，因此不确定最终倒数与完成区域之间的具体过渡动画。主动退出则直接回到设置，没有显示上述完成区域。
