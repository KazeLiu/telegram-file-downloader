- 所有同组附件入队；分卷等待已知卷下载齐全、编号连续且 7-Zip 完整性检查成功，再解压。不同转发组隔离。

- 工作流可视化、文件管理/预览整理、持久化日志，以及文件/队列暂停、继续、失败重试。小米云相册仅待接入标签，不调用云服务。
- 保留登录、设置、历史、旧 CLI 入口和首次不扫旧消息的语义。已有完成资源不自动进行破坏性追溯整理。

## 现状与约束

- 历史扫描等待 `process()` 完成下载，且整个下载持有 operation_lock；一个文件请求无返回会挡住后续扫描、设置和重连。分片 await 没有业务超时。此为源码确认的阻塞路径，用户服务器断线的具体诱因尚无足够日志。
- 将任务接收与执行拆开：持久化任务后推进扫描检查点，worker 从日志恢复任务；同一事件循环拥有 SQLite 和 Telegram 会话。
- 文件系统操作限下载挂载内，拒绝符号链接/越界；整理逐项记账以支持中断恢复，移动成功再清理空目录。预览确认只针对所选文件夹。

## 实施顺序

1. 持久化任务/分片检查点、日志与有界请求等待；网络失败保留进度。
2. 五 worker 调度、账号级共享限流、控制操作、扫描与执行生命周期；分卷组隔离和重试。
3. 解压完整性检查、根目录扁平化/PDF 清理及可恢复操作记录；文件管理 API。
4. Vue 工作流步骤、并行任务列表与控制、文件预览/手动整理、日志查看；复用现有 Apple 风格。
5. 源码与差异检查、Python 语法编译和前端构建；沿用已授权独立本地页面检查。按已有授权推送并跟进 GHCR 发布。
