# 小米云上传日期与三文件并发

## 目标与依据

- 上传保留原图和历史时间线，不再统一使用上传当天。
- 官方 Windows 客户端 4.0.1 提交 `dateTaken` 和 `dateModified`，最多同时处理 3 个文件。
- 实际导入「主视觉.png」后，云端 `dateTaken`、`sortTime` 为 1790152905215，`dateModified` 为 1789887737000；记录创建于本次导入时。
- 官方实际返回的 HTTPS 上传节点 `kssh2.xmssdn.micloud.mi.com` 目前被项目上传白名单误拒。

## 实现范围

- [x] 共用上传入口读取原图 EXIF 日期，缺失时用文件创建时间、修改时间；提交原修改时间，浏览器入口传递 `File.lastModified`，不使用临时文件创建时间冒充原文件日期。
- [x] 仅补充已确认的小米存储域名，保留 HTTPS、端口、跳转和凭据隔离校验。
- [x] 批量上传最多 3 个文件并行；暂停和停止等待在途文件完成，停止不再领取新文件，限流或账号错误停止后续调度。
- [x] 保留云端核对后才能回收本地文件、暂停恢复、关闭清理与原文件变化检测；统一 Windows 路径与文件句柄的创建时间版本校验，Linux 保留原 ctime 语义。
- [x] 同步进度文案、说明和受影响的断言检查；不增加项目依赖，不修改其他审阅功能。
