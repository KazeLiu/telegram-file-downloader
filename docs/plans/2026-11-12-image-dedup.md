# 绑定目录图片去重

## 目标与边界

- 主菜单新增“图片去重”，多选当前小米账号已绑定的本地目录；递归扫描并统一比较目录内、目录间的图片。重叠目录中的同一文件只出现一次。
- 内容摘要识别完全重复，64 位 DCT 感知哈希建立相似连通分组；打开分组后按用户选择的参考图计算标准灰度 SSIM（11×11 高斯窗口，sigma=1.5，较小尺寸、长边上限 1600）。本项目独立版本化算法，不混用 ImageKeeper 缓存或分数。
- 不指定受保护基准，不预选、不自动删除；用户逐张勾选。确认页按所属绑定相册中的“文件名＋大小”定位全部云端对应项，采用用户确认的对应关系，不下载云端原图。
- 先将所选本地文件移入现有应用回收站，再回收确认的云端项。分别持久化结果，云端失败可以手动重试；本地已还原后不继续旧的云端清理。原有云相册联动回收入口保持原流程。

## 实施顺序

1. 新增独立图片算法模块和 NumPy 运行依赖；复用 Pillow、路径边界、目录遍历与回收站。仅为内容去重计算摘要，不给云本映射添加额外校验。
2. 新增去重服务：缓存特征、保存当前扫描与分组、取消扫描、分页查看结果/错误、缩略图与原图审阅、按需 SSIM；绑定或文件变化后拒绝使用过期选择。
3. 接入云端匹配预览、逐项确认回收和持久化失败重试；新接口沿用管理鉴权、账号隔离和现有文件操作锁。
4. 新增 Vue 页面和主导航，左侧分组、右侧图片比较，底部已选操作栏；原图审阅、参考图切换和分组/图片分页均可操作。
5. 更新使用说明，阅读调用链并检查差异；构建前端与 Python wheel，按项目规则提交、推送 `origin/master`，确认镜像工作流和两个标签。

## 验证与恢复

- 不新增、修改或运行测试，不启动应用或浏览器；视觉与真实文件/云端联动由用户验收。
- 构建不能证明真实相册删除成功；开发过程中不调用任何实际回收接口。
- 新缓存位于数据卷中，不改变原有绑定库。扫描中断可重新扫描并复用未变化的特征；执行记录按回收 token 恢复，不重复回收已完成项。
- 本地回收沿用现有 15 天保留策略，云端恢复仍在小米云回收站操作。
