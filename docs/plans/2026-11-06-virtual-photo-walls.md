# 虚拟照片墙与日期选择

## 目标

- 本地图片快筛和小米云图片墙只挂载视口附近的图片行，保持页面滚动、日期分组和现有响应式列数。
- 日期前显示可点击勾选符号，支持全选、部分选中和未选中。选择作用于该日所有已加载图片，不限于已挂载节点；该日后续加载的图片延续日期选择。手动取消一张后停止该日的自动续选。
- 本地普通浏览时点按、长按均进入快速审阅；整理模式点按仍选图，长按审阅。保留相邻图片、键盘操作和回收确认。
- 选择状态由页面持有，滚出视口不丢失。回收继续局部更新，成功自动关闭确认弹窗。

## 实施

- 使用 TanStack Vue Virtual 的 window virtualizer，复用现有 CSS 网格列数，按日期标题及图片行虚拟化。
- 共用日期分组和行布局，两个页面保留各自图片操作；不引入新的滚动容器，不全量扫描云端。
- 使用隔离模拟数据检查大量图片后的 DOM 数量、日期续选、长按审阅、回收和窗口缩放；不操作真实照片，不运行测试套件。
- 相关构建通过后提交并推送主线，核对 Docker 发布流程和 latest / sha 标签。发布不更新线上容器。

## 验收记录

- 前端类型检查及静态构建通过。保留分组与行布局的独立断言检查源文件，未运行测试套件。
- Chrome 插件内使用 5000 条已加载模拟数据，本地初始挂载 240 个图片节点、云端初始 80 个；深层滚动仍只挂载视口附近节点。
- 日期全选覆盖离屏数据，并能随同日追加续选；取消一张显示半选、停止该日续选，滚动卸载不丢失选择。
- 在整理模式实际长按 650ms，进入快速审阅并可切换相邻图片；时间及来源随审阅显示。
- 390px 窄屏及宽屏切换保持在原照片附近。虚拟墙排除浏览器原生滚动锚定，由布局调整保持阅读位置。
- 虚拟墙回收后 5100 条变为 5099 条，滚动偏移保持不变，成功弹窗自动关闭；未操作真实照片。
