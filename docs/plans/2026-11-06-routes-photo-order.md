# 页面路由与照片时间顺序

## 已确认

- 功能页、相册内部、本地图片视图、文件目录和下载详情使用可刷新的 URL；保留前进、后退。
- 使用 Nuxt 内置 hash 路由，兼容现有 Docker 静态页面，不改变 18880 端口。
- 官方 PiliPlus 样本前 30 张与项目一致，服务按 `sortTime` 从新到旧返回，官方照片墙按日分组。保留服务分页，时间优先使用 `sortTime`。
- XiaomiAlbumSyncer 以 `dateTaken` 保存照片时间。本地索引优先 EXIF 拍摄时间，其次图片日期、文件系统创建时间、修改时间；不按名称排序，不改写原图。Linux ctime 不作为创建时间。
- 回收规则维持项目回收站 15 天后容器永久清理，不引入 host-tools。
