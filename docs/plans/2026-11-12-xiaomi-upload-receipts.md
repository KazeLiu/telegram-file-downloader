# 小米上传回执与重启恢复

## 目标
- 关页、重启、切换批次后仍可查看逐文件回执和回收已确认的本地图片。
- 新批次默认选择未上传文件；按账号、相册、目录和本地文件版本区分，不凭同名判定。
- 为旧版丢失回执提供只读找回：扫描目标相册，核对文件名、字节数及 SHA-1；匹配成功后进入可回收批次。

## 实现顺序
1. 在现有 ConsoleStore 数据库增加上传批次和逐文件日志，按文件进度提交；恢复时将中断任务标为停止，不自动上传或删除。
2. 批次 API 支持历史查询，候选列表标记已上传版本；继续复用云端核对、本地版本核对和项目回收站。
3. 增加后台找回任务，只读云端和本地内容，逐项保存确认结果；错误或未匹配保留原文件。
4. 上传弹窗提供批次历史、待清理数量、默认只选未上传和找回操作；新批次不覆盖旧结果。
5. 更新使用说明，阅读差异与调用关系，执行 Python 语法编译和现有前端构建；按既定流程提交、推送并确认 Docker 发布。

## 边界与恢复
- 不启动应用或浏览器，不新增或运行测试，不操作用户真实相册或删除真实文件。
- 旧内存回执不能原样恢复；找回得到的是当前目标相册内内容一致的记录，不推测原批次时间。
- 回收前再次核对云端编号、摘要、大小和本地版本；无法确认的文件保持原位。
