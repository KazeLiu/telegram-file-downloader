# 分卷归组与手动解压

- 收集记录按同账号/群、原来源、文件基础名、分卷格式识别；无重复卷号的未完成批次可以跨媒体组展示为一组。有重复卷号时保留原批次并提示，不猜测混合。
- 展示分组独立于物理下载目录，不迁移历史文件或分片。记录分页按组计算，详情保留每卷进度与速度。
- 新增“仅解压到文件夹”：检查整组空闲及确认清单，临时硬链接汇集不同目录的分卷，以现有 7-Zip 安全检查解压到下载根目录中的独立文件夹。保留原包，不平铺、不回收 PSD/TXT、不上传。
- 新增“标记为手动解压”：整组写入终态及标记时间，不检查原包存在与否，不改磁盘文件；重启后不再自动重试。后台活跃任务拒绝此操作，确认清单变化要求重新打开。
- 图片管理继续只看根目录；仅解压后的目录由用户在文件管理中手动整理。
- 现有自动解压/整理入口和暂停、继续、重试语义保持；手动模式失败后的重试只重新解压。
- 按用户约定仅做源码、调用关系和差异自查；本轮不新增/运行测试，不启动应用或浏览器。提交与镜像发布沿用本项目既有授权，只提交本次文件，保留其他工作。
