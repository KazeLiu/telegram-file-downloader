# 播放选择与播放器完善

## 目标

按 `PLAYBACK.zh-CN.md` 及其本地交互设计完善现有播放器，不访问参考网页，保留图库只读接口和既有播放列表。

## 工作项

- [x] 播放前按播放、媒体、声音、显示组织设置，提供实时摘要和配置导入、导出、恢复默认。
- [x] 播放中可暂停打开设置，独立控制媒体、节拍与语音音量；显示设置不重建队列或改变计时。
- [x] 增加每轮图片数（0 为全部）；全浏览器共用已展示图片记录，仅可见且成功加载的图片计入。
- [x] 每次开始和循环换轮从未展示图片中选择；数量不足才重置所选图片范围，未展示、预读及加载失败的图片不计入。
- [x] 首批 20 项流式返回，原接口保留；图片缓存上限 20 张、预取并发 2，展示前 HEAD 校验版本。
- [x] 更新说明与定向自查，构建并检查实际界面。

提交推送与镜像标签按项目 `AGENTS.md` 的发布流程执行，结果以本次提交及 GitHub Actions 为准。

## 约束与验证

- 保持图片时间/BPM切换、混合和视频播放、暂停剩余间隔、全屏、喜欢及错误恢复。
- 旧配置只补新增字段；导入验证后确认替换，仅导入播放配置，图库按本机已注册目录重新选择。
- 不加入远程协作、摄像头、提示编辑器、预设、分享或成绩。
- 给选图和配置迁移保留小型断言检查；运行验证以构建、调用关系与差异为主。
- 界面检查仅使用合成媒体，不读取或修改真实图片；保留用户已有文档改动。
