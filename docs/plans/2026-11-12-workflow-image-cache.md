# 工作流选定目录与增量缓存

- 在“图片去重”页增加“工作流自动检查”开关，开启后显示已绑定本地目录的多选列表，显式保存。设置按小米账号持久化，默认关闭、未选择目录；不自动把后来绑定的目录加入范围，不改变手动去重的目录选择。
- 保存启用后优先准备所选目录的文件清单与图片特征；已有有效清单和特征直接复用。每批新图片只唤醒比对，不刷新全部备份清单。所选清单仍接受六小时检查、手动刷新及已有回收/还原触发的更新。
- 常驻内存维护感知哈希索引；参考清单发布后只解码新增或变动文件，删除项从索引移除。重启通过 SQLite 缓存恢复，不逐张 stat/解码未变化的备份图。目录清单生成号改变但实际图片未变化时，不作废旧比对结果。
- 在现有去重数据库保存工作流参考文件版本清单和引用版本号；实际参考内容新增、变化、删除后使旧的未命中结果也重新评估，复用已有 SSIM。范围、账号或算法改变时旧结果不可混用。
- 自动功能关闭时不准备特征、不检查图片；保留缓存以供重启用。取消选择或解除绑定的目录立即退出自动范围。工作流和“重复图”页展示开关/准备缓存/检查状态。
- 沿用用户验证约定：阅读调用链和差异，不新增或运行测试、不启动应用或浏览器；执行前端构建、Python 编译/打包，再提交主线、确认 GHCR 两个镜像标签。大图库性能和真实联动仍由用户验收。
